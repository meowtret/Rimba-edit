about=A set of tools for digitizing and maintaining parcel data (forest compartments, blocks, permit areas, land parcels) in QGIS. Every tool records its changes as a single undo step, is safe for GeoPackage, PostGIS and SpatiaLite layers (primary key fields are never copied, so saving does not fail on UNIQUE constraints), and supports Z/M geometries. Tools: explode multipart features, repair invalid geometries, copy attributes to selected features, quick multi-field fill, find and replace values, copy feature coordinates (layer CRS or WGS84 DD/DMS), ellipsoidal area calculation in hectares or square metres, mandatory field validation with highlighting (keeps the original layer style), export attributes to Excel, and a topology checker for polygons (invalid, overlaps, gaps, slivers) and lines (crossings, dangles) that writes findings to review layers. The user interface is in Indonesian. Forked from "Editor Bidang dan Atribut" by Fajar SNI (GPL-3.0).
