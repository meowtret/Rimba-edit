about=Kumpulan alat untuk digitasi dan pengelolaan data bidang (petak, blok, areal izin, persil) di QGIS. Semua perubahan dicatat sebagai satu langkah undo, aman untuk GeoPackage/PostGIS/SpatiaLite (kolom ID utama tidak ikut disalin), dan mendukung geometri Z/M. Dikembangkan dari plugin "Editor Bidang dan Atribut" karya Fajar SNI (GPL-3.0).

    0.9.2 (2026-11-02)
    - Alat Tukar Atribut, Pemecahan Bidang, dan Penomoran Akhiran Otomatis dihapus

    0.9.0 (2026-11-02)
    - Fork dari Editor Bidang dan Atribut 0.1.1 (Fajar SNI) dengan nama baru Rimba Edit
    - Kompatibel Python 3.9+ (sebelumnya gagal dimuat di Python < 3.12)
    - Kompatibel QGIS 3.22 s.d. QGIS 4 (Qt5/Qt6)
    - Kolom ID utama (fid/PK) tidak lagi ikut disalin/ditukar: tidak ada lagi galat UNIQUE/duplicate key saat menyimpan
    - Setiap alat = satu langkah undo
    - Dukungan geometri Z/M dan penyesuaian otomatis single/multipart
    - Hitung Luas: satuan ha/m², opsi buat kolom baru, aman untuk CRS geografis
    - Validasi: statistik NULL akurat, gaya asli layer tidak hilang (style manager)
    - Ekspor Excel: aman untuk NULL/tanggal, cadangan tanpa openpyxl, huruf Arial
    - Cek Topologi ditulis ulang: indeks spasial, deteksi celah yang benar, layer hasil untuk ditinjau, deteksi dangle
